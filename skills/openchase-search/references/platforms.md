# What each platform is good for

| Platform | Use it for |
|---|---|
| `publications` | Reporting and analysis from news sites, magazines and blogs |
| `x` | Breaking reactions, live commentary, public figures |
| `reddit` | Detailed first-hand experiences, complaints, community opinion |
| `youtube` | Reviews, explainers, event footage |
| `instagram` | Visual launches, brands, creators, lifestyle |
| `tiktok` | Trends, younger audiences, product reactions |
| `linkedin` | Business, hiring, industry and company news |
| `threads` | Conversation similar to X |
| `facebook` | Local communities, groups, pages |
| `substack` | Newsletters and long-form opinion |
| `medium` | Long-form posts, often technical |

Defaults when nothing fits better: `x`, `youtube`, `instagram`.
